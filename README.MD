# Padrões de Projeto de Software

## CST em Sistemas para Internet

Este repositório reúne as atividades práticas desenvolvidas na disciplina de
Padrões de Projeto de Software do curso de CST em Sistemas para Internet.

O objetivo é registrar os exercícios, exemplos e implementações realizados ao
longo da disciplina, aplicando conceitos de orientação a objetos, refatoração e
padrões de projeto no desenvolvimento de software.

As atividades presentes neste repositório fazem parte do processo de estudo e
aprendizagem da disciplina.
